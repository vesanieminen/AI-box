Manual benchmark configurations

All configurations use TP = 2 and one request at a time, with 175 W per GPU. Every main model targets its full native 256K context, as requested. Memory fit and long-context quality remain unverified; Gemma INT8 has the tightest memory budget. Keep 256K unless reliable evidence establishes that it cannot fit or does not work at that context; then lower only the affected configuration to the largest fitting and working context. Qwen/Ornith plan FP8 E4M3 attention KV; Gemma plans automatic 16-bit FP16/BF16 KV. Precision labels describe saved plans, not a measured running server. The shared DFlash draft’s actual cache dtype must be checked at startup. All main model configs advertise a 256K maximum. Runtime cache capacity, workspace allocation and long-context output still need testing. No automatic benchmark is scheduled; model loading waits for your instruction.
